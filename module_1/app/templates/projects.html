02 / MODULE 2

Graduate Admissions Data Pipeline

A responsible Python web scraper that collected and validated 30,000 public graduate admissions results from GradCafe for Modern Software Concepts in Python at Johns Hopkins University.

The pipeline checks robots.txt, follows cursor pagination, saves restartable checkpoints, preserves source evidence, and uses a locally hosted TinyLlama model to standardize program and university names without changing the original data.

Graduate Admissions Database & Analysis

A PostgreSQL-backed analysis application built from 30,006 graduate admissions records collected through the Module 2 data pipeline.

The project combines raw SQL and SQLAlchemy ORM queries with a responsive Flask dashboard. It supports safe incremental data collection, duplicate prevention, live analysis updates, and documented findings about the limits of self-reported admissions data.
