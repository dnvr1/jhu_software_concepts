Module 1 Assignment: Personal Developer Website
Author: Denver Clarke
Course: EN.605.256 Modern Software Concepts in Python

DESCRIPTION

This project is a personal developer website built with Flask, HTML, and
CSS. It includes Home, Projects, and Contact pages with a shared navigation
bar, reusable templates, and Flask Blueprint routing.

SETUP

Python 3.10+ is required.

Create and activate a virtual environment:

python -m venv venv
.\venv\Scripts\Activate.ps1

Install dependencies:

python -m pip install -r requirements.txt

RUN

Start the website with:

python run.py

Open:

http://127.0.0.1:8080/

Pages:
Home: http://127.0.0.1:8080/
Projects: http://127.0.0.1:8080/projects
Contact: http://127.0.0.1:8080/contact

Press Ctrl+C to stop the server.
